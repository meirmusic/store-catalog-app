# Share-card fonts (SPEC.md 23.5)

Bundled so the designed share card is drawn the same on every device, also offline.
Closest free matches to the 2025 catalog's fonts. From @fontsource 5.3.0 (Hebrew + Latin subsets only).

| File | Font | Used for |
|---|---|---|
| frank-ruhl-libre-*-700 | Frank Ruhl Libre Bold | the artwork name (the catalog's Hebrew titles use EFT Besimches) |
| assistant-*-400 | Assistant | size · type (as in the catalog) |
| cormorant-garamond-latin-500 / 300-italic | Cormorant Garamond | price; the "Art that speaks to your soul" tagline (as in the catalog) |

All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
